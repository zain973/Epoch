Role: Reader (General Public)
Page: /feed (The main landing page showing articles)
  Component: <TopNavbar /> - Fixed header containing application branding and a "Write a Post" CTA button.
  Component: <FeedContainer /> - The responsive layout that runs the GET request to fetch the global chronologically sorted feed from the FastAPI backend.
  Component: <ArticleCard /> - A Shadcn Card rendering post metadata (title, author, tags, date). Simple click event that routes the user directly to the full article page.

Role: Author (Content Creator)
Page: /write (The publishing dashboard)
  Component: <TopNavbar /> - Reused global navigation bar for branding consistency.
  Component: <PublishForm /> - A Shadcn Form utilizing react-hook-form with input fields for Title, Content, and Tags. Wired directly to the POST /api/articles backend endpoint.
